# Vilmuse Studio - Carousel Website

**Nama:** Vianlienra Hung  
**NIM:** 535250012

## Deskripsi

Vilmuse Studio merupakan single-page website bertema sekolah musik yang dikembangkan menggunakan Next.js, React, TypeScript, dan React-Bootstrap.

Website ini dirancang untuk memperkenalkan program pembelajaran musik dengan tampilan yang elegan, responsif, dan mudah digunakan.

## Fitur

- Responsive navigation bar.
- Active menu styling berdasarkan section aktif.
- Hero carousel dengan tiga slide.
- Automatic carousel transition.
- Carousel navigation controls dan indicators.
- About section.
- Music programs section.
- Contact section.
- Responsive desktop, tablet, dan mobile layout.

## Teknologi

- Next.js
- React
- TypeScript
- React-Bootstrap
- Bootstrap 5
- CSS

## Cara Menjalankan

```bash
npm install
npm install react-bootstrap bootstrap
npm run dev
```

Buka http://localhost:3000 pada browser.
